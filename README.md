# Real Estate Data Analysis and Price Prediction

## Project Overview
This project analyzes 250,000 real estate records from different Indian cities using Python. It also explores whether machine learning can predict property prices.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Objectives
- Analyze real estate prices across different cities.
- Compare prices of different property types.
- Explore relationships between property features and prices.
- Build and evaluate machine learning models.

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- Dummy Regressor (Baseline)

## Key Findings
- The average property price was approximately ₹254.59 lakhs.
- The dataset contained properties from 42 cities.
- Independent houses had a slightly higher average price than apartments and villas.
- The selected numerical features showed very weak correlations with property prices.
- The machine learning models performed poorly and did not improve meaningfully over the baseline.

## Conclusion
This project demonstrates data cleaning, exploratory data analysis, visualization, and machine learning. The results suggest that more informative features or better-quality data may be needed for reliable property price predictions.
